# 工作管理与效率功能

此轮在原有 Jira 数据和权限上增加工作视图、批量处理、工时复盘、版本进展及本地通知。未新增独立项目管理数据库，Jira 继续保存业务数据；视图、列设置和已读记录保存在当前电脑，按 Jira 地址、用户、项目隔离。

## 页面操作入口

- 需求树主操作为“新建需求”，子任务和 Bug 从具体需求下添加；全部问题保留“新建问题”类型菜单。看板聚焦现有事项的拖拽流转；版本进展使用已有风险筛选、进展复制和导出，不增加通用新建。工作台使用“添加卡片”，工时使用“从日报新建”，通知中心与 MCP 使用各自页面操作。快捷键 C 仅在需求树与全部问题生效。
- 工时统计与检查/汇总合并为一个侧栏入口，通过标签页切换；旧 `#/项目/review` 地址自动转到 `#/项目/hours?tab=review`，保留问题详情；标签切换同步地址、支持后退与刷新，已访问标签保持当前设置。

## 我的工作台

- 首页恢复多张任务清单卡片，默认待处理、开发中、待测试 / 验收、临期与逾期；每张默认显示5条，可展开或进入完整列表。
- 项目仍在左上角侧栏统一切换，工作台不增加第二个项目选择器。全部卡片跟随全局项目，布局按 Jira 地址和账号保存在当前电脑，各项目共用。
- 添加卡片可选择内置工作视图、自定义筛选，或把当前项目旧版已保存工作视图转为卡片；旧版数据保留。
- 自定义条件包括人员关系（经办、开发、测试、与我相关或所有人）、工作条件、多个阶段/类型、实际优先级、影响版本、标题/编号包含、到期日期区间。不同字段同时满足；同字段多选满足任一。
- 卡片支持更新时间、到期日、优先级ID排序，3/5/8/10条，半行或整行。卡片可直接拖动标题排序，右下角手柄按四轨网格调整宽高，支持键盘方向键；松手自动保存，无需进入编辑模式。默认两列且同行等高，手动高度只影响当前卡片；手机保持单列并按内容自适应。卡片配置菜单中可恢复自动高度或移除卡片，移除不影响 Jira 问题，最多20张。
- 卡片“查看全部”沿用相同筛选条件打开可配置表格，保留批量处理、列布局、排序和CSV导出；表格排序可单独调整。
- 默认查询经办人、开发人员、测试人员任一为当前用户的事项；存在“项目内所有人”卡片时，扩大为当前项目所有人，各卡片仍分别应用人员条件。所有未解决事项及近30天解决事项参与查询，最多1000条；超限明确提示，计数、筛选与导出均基于已加载结果。
- 所有卡片共享一批数据，刷新或问题修改后统一更新；切换项目取消旧请求并关闭卡片配置/完整列表，避免旧项目数据串入。
- 今日待办为今天到期或今天开始开发的未完成事项。被阻塞只看未完成入向 Blocks 依赖，排除“子项 blocks 父需求”关系。
- 待补工时检查缺开发人员、缺少或无法解析的开发预估时间、缺开发完成/解决日期；未结束任务也可能缺完成日期，不填假日期。

## 加载与界面性能

- 工作台元数据与第一页并行读取；首批最多100条先渲染，后台按页补全至最多1000条。首批及后台补页时明确显示“统计补全中”，失败保留已加载内容并提示，不把部分数据当成完整统计。
- 同项目、同筛选的同页查询共享 Promise，短期复用20秒；字段、项目、优先级等元数据缓存5分钟。本地代理按登录会话隔离缓存，失败不缓存；退出、切换 Jira 地址、任何 Jira/MCP 写入均清空对应缓存。
- 会话 cookie、人员搜索、mypermissions、附件等不进入公共读取缓存。手动刷新与写操作成功后的 bump 会失效前端缓存并重新查询。
- 项目、字段 API 的 AbortSignal 传到底层 fetch；本地代理合并重复 GET 并绑定调用方断开，避免快速切项目后继续积累无用请求。浏览器取消只退出自己的等待，其他组件使用同一请求时不会互相误取消。
- 同一账号在项目间保留工作台快照，临时结果有明确同步提示；不写 Jira 业务数据库，不将缓存当成已保存的写入结果；同步失败时禁止从过期清单进入批量处理，需先重试成功。
- 首页卡片采用等高任务槽位，标题区、任务区和底部操作对齐。悬浮工作台支持浅色/深色主题、加载骨架、克制的 hover 与详情动效，并遵循系统“减少动态效果”设置。

## 可配置列表与批量操作

工作台、全部问题、工时复盘及版本进展使用可配置列表：

- 显示/隐藏状态、所属需求、经办人、开发人员、影响版本、优先级、到期、创建和更新时间；调整列顺序及宽度。
- 按更新时间、到期日、优先级、编号或创建时间排序。“全部问题”排序在 Jira 查询中执行，其他管理页排序作用于已加载结果。
- 全部问题可命名保存“筛选条件＋列布局＋排序”，删除、重新打开；复制筛选链接供他人在各自有权限的工作台查看。链接中不包含凭据，但包含筛选关键词。
- 导出当前列表结果为 UTF-8 BOM CSV，字段文本按 CSV 转义，并抑制 Excel 公式执行。项目列表为当前页结果；管理页为当前已加载并筛选结果。
- 多选仅允许工作台可写项目，每次最多50条；不跨页隐藏勾选。完成后清空勾选。

批量支持修改共同可编辑字段、单步状态流转、添加备注、挂父需求：

1. 读取每条问题详情、editmeta 和当前 transitions。
2. 选择变更并预览：修改字段显示原值/新值；相同值跳过。预览不写 Jira，可以返回修改。
3. 确认后逐条执行，重新检查相关字段、元数据与流转是否变化。
4. 展示逐条结果；失败不回滚已成功记录。响应不确定时停止后续写入并要求核实，不提供盲目重试。

批量流转必须 ID、名称、目标状态一致，且字段合法。挂父需求只允许非需求问题；有不同父需求时拒绝批量换父，要求单独处理。备注按各问题评论权限预检。Jira 仍负责最终权限校验。

前置/后置检查可以发现部分并发变化，但 Jira 6 接口不支持跨任务事务，也不能保证检查与写入之间不会发生外部修改。

## 工时检查与汇总

工时检查与汇总已合并到“我的工时 → 检查与汇总”标签页：

- 今日、本周、上周、本月、上月和自定义日期范围。
- 日报/周报汇总沿用开发预估时间、开发完成日期（缺失则解决日期）、开发人员是我的默认口径；需求有子项时只计子项，默认排除关联父需求的 Bug。
- 一键复制含编号、标题、日期、工时和当前状态的文本；导出明细 CSV。文本不把尚未完成的任务标成已完成。
- 工时完整性检查覆盖我参与的未结束事项或近30天更新事项。无日期事项单列，无法推断归属哪天，不偷偷计入区间报表。
- 点异常事项打开详情补填；也可以多选共同工时字段批量补填。
- 原“我的工时”增加命名统计方案，可保存当前日期口径、人员、问题类型、筛选和面板，再次选择恢复。每项目最多20个方案。

## 版本进展

新增侧栏“项目 → 版本进展”，仅具体项目可用：

- 按项目影响版本选项（包含未设置版本）查询，最多1000个问题，超限明确标记不是全量统计。
- 显示按问题数计算的完成比例和未完成、未关闭 Bug、逾期、未分配、被阻塞清单。
- 展示需求子项进度；链接可能跨版本，该子项比例不等于版本内比例。
- 复制版本摘要；风险列表可直接打开问题或批量处理。
- 此页不会修改版本发布状态，检查结果不代替测试或验收。

## 通知中心

新增侧栏“个人 → 通知中心”：

- 聚合个人查询范围内逾期、临期、阻塞、工时缺失，以及当前用户 MCP 失败/部分完成记录。
- 比较本机前后两次读取，记录状态、经办人和影响版本变化；首次打开建立基线，不生成历史变化。
- 类型筛选、只看未读、逐条或当前结果全部已读；点击问题打开详情，MCP 失败跳转设置页。
- 页面打开时每60秒和窗口重新聚焦时刷新，后台隐藏时不轮询。关闭页面/工作台后不继续执行。
- 本阶段不包含系统推送、企业微信、完整评论或附件事件订阅。已读只表示看过提醒，不表示风险解除。

## 验证

规则测试覆盖日期边界、父子与阻塞区分、工时去重和 Bug 排除、通知差异、配置清洗、CSV 公式防护、批量无效输入。

真实浏览器使用本地模拟 Jira 接口验证：工作视图保存恢复；批量字段/备注/流转/父需求预览零写入、确认执行、部分失败、外部字段冲突保护；列设置、CSV、分享；日报文本、统计方案、版本风险、通知已读和变化；390px宽屏幕布局。没有写入真实 Jira。
