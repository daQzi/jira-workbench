# 工作台视觉动效与 3D

## 范围与目标

- 工作台默认仍是二维管理界面。通过克制的标题光晕、卡片高光和换位过渡改善反馈，不使用全屏粒子、持续鼠标拖尾或卡片翻转。
- 登录页显示需求、任务与工作节奏的轨道场景；工具箱提供“工作星图”小彩蛋，支持暂停、旋转视角、拖动旋转。场景不代表项目拓扑，也不虚构任务数据。
- 使用 `@react-three/fiber@9` 与 `three` 的 MIT 依赖，版本由 lockfile 固定。模型、纹理、字体和 CDN 均未引入，几何体与颜色在本地代码生成。

## 持久化设置

- `wb.motion.v1`：`normal` / `reduced`，默认轻动效。
- `wb.scene.v1`：`auto` / `on` / `off`，默认自动。
- 登录页和工具箱的“界面动效”共用设置；无 Jira 会话也可调整。写入失败不阻断登录与业务功能。
- 自动模式在系统 `prefers-reduced-motion: reduce`、用户选择减少动画或 WebGL 不可用时使用静态 SVG。显式开启表示用户主动选择 3D，仍处理创建失败与上下文丢失，失败回退到静态图。
- 设置不是跨设备同步数据，也不进入工作台业务备份。

## 渲染边界

- `OrbitCanvas` 由动态 import 拆成独立块，仅登录页或打开工作星图时加载；首页主包不直接包含 Three.js。
- 限制 `dpr` 为 1–1.5、使用 low-power；无 Bloom、折射、后处理、动画模型或大量粒子。场景离开视口、页面隐藏或用户暂停时停止帧循环。
- 渲染错误边界捕获场景失败；WebGL 上下文丢失后回退静态图形。渲染能力检查通过不等同于保证所有设备可创建 WebGL，最终由浏览器实际测试和错误边界兜底。
- 390px 登录页改为场景在上、表单在下；减少动效会关闭默认过渡。暂停只影响工作星图，登录页仍遵循设置。

## 卡片拖拽与缩放

- 拖拽采用 `@dnd-kit/core` 6.3.1 + `@dnd-kit/sortable` 10.0.0（MIT），网格使用 `rectSortingStrategy`，碰撞使用 `closestCenter`；不改变卡片顺序/宽高/隐藏的数据结构。
- 指针移动 7px 后激活；标题作为唯一拖拽把手。输入框、菜单、链接、按钮和缩放手柄不启动排序。拖动期间原卡片隐藏，`DragOverlay` 副本跟手，其他卡片按 240ms 的 `cubic-bezier(0.2,0.8,0.2,1)` 平滑让位，松手 240ms 回落并一次保存；减少动效时关闭过渡。
- 键盘沿用 dnd-kit KeyboardSensor：空格/回车抓取，方向键移动，空格/回车放下，Esc 取消。不要再叠自定义 keydown 处理，否则会与传感器递归触发。拖拽结束后必须清理 overlay 和 body class，避免透明副本遮挡后续点击。
- 缩放不再逐帧 `setState`：指针移动只直接写目标卡片的高度和网格跨度，使用 `requestAnimationFrame` 合并高度更新，松手才写入 localStorage。Esc 恢复保存值；20px 高度吸附、1–4 轨宽度吸附由 `resize.ts` 纯函数测试。
- 不使用 HTML5 原生 drag；手机保留单列指针拖动，右下缩放手柄在窄屏隐藏。
- 固定高度卡片的头部和页脚不收缩，任务区独立滚动；可见任务数按可用高度计算，避免标题与首条任务、任务与页脚互相遮挡。
- 自动高度卡片同样遵守3/5/8/10条预览设置，完整结果通过“查看全部”进入分页列表。任务筛选结果按数据和条件预计算，拖拽外壳与内容分离，避免每次指针移动重新筛选和渲染全部任务。
- 排序只回传可见卡片 ID，在完整配置中合并可见顺序，隐藏卡片保留原位置和配置。
- 缩放期间显示列宽/高度提示和网格参考线；跨度改变时相邻卡片使用180ms位置补间，减少动画时关闭。指针取消、失焦、Esc 和组件卸载均恢复已保存尺寸并清理临时状态。
- 手机同时解除卡片内外层固定高度和内容区的零基础 flex 分配，避免任务区域被压成几像素。
- 工作星图角度保存在 ref 中，帧内合并指针变化；拖动不重挂载场景或 Canvas。暂停时使用按需渲染，手动旋转会触发一帧；页面隐藏或场景离开视口时暂停自动渲染。

## 验证

- 构建拆分检查：首页包与独立 `OrbitCanvas` 块。
- 实际浏览器 WebGL：工作星图渲染、暂停恢复、旋转视角、拖动；关闭与减少动效后的 SVG 降级；登录页场景与手机布局。
- 实际鼠标轨迹拖拽、顺序刷新恢复、键盘排序、Esc 取消；同时回归卡片配置、尺寸、隐藏、删除撤销、工具箱、备份与明暗主题。
- 缩放实测 95% 帧间隔约16.7–16.8ms，无超过50ms的帧；缩放后刷新尺寸保留，Esc取消恢复原尺寸。此为本机 headless Chrome + 模拟 Jira 的结果，不代表所有设备。
