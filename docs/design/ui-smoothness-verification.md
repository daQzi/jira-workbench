# UI 流畅度优化与验证

日期：2026-11-14。检查基线：`4e74ee0`（v2.3.0）。本次未增加前端依赖，未修改 Jira 接口或数据库。

## 实现边界

- 卡片网格只管理位置；完整卡片配置负责合并可见顺序，隐藏项不随排序丢失。卡片筛选结果预计算，内容与拖拽外壳分离。自动高度同样遵守预览条数，完整列表每页100行。
- 缩放继续使用 DOM 与 requestAnimationFrame 合并更新，松手保存一次；补充尺寸提示、网格参考线和跨度变化时的邻居位置过渡。Esc、指针取消、失焦和卸载清理临时状态。
- 便签、待办、工具箱和备份导入共用账号级 ToolsProvider；保存前校验并读取最新本机数据，写入成功后才更新共享状态，监听其他标签页的工具存储变化。
- 详情主体与子项独立加载；需求树在展开后才补齐子项。本机组件不等待 Jira。行内保存仅锁当前编辑区，原写入去重、创建和批量提交保护继续保留。
- 弹窗、抽屉和图片预览共用焦点管理；手机导航折叠，项目保留左上角；附加筛选可收起且显示已选条件；骨架、悬停、状态色和按钮按主题变量显示。
- 看板快照在 state updater 外合并持久化；低频页面和复杂弹窗按需加载。星图使用 ref 更新旋转角度，保留 Canvas，暂停时按需渲染。

## 浏览器验证

使用本机无头 Chrome、生产 dist 与模拟 Jira，视口1440×1000及390×844。所有写请求均由模拟接口处理，没有写真实 Jira。

- 排序保留隐藏卡片；便签从卡片到工具箱、从工具箱到卡片双向同步。
- 缩放中显示尺寸但不写存储；松手保存，刷新保留；Esc取消不改变保存值，方向键可调整尺寸。键盘支持抓取、换位、放下。
- 完整列表100行一页；当前页全选与取消不覆盖其他本地页选择，导出仍包含1000条已加载结果。
- 手机固定高度卡片任务区从原4px恢复为94px/454px；导航宽度不再超出视口。
- 弹窗连续Tab保持在内部；关闭后返回入口，快速跳转含 autoFocus 时也恢复入口焦点；图片预览Esc只关闭预览。
- 桌面同行自动高度卡片对齐；卡片菜单内的指针移动不启动排序。浅色、深色和手机菜单截图已检查。
- 人为延迟 Jira 搜索时便签仍可新增；延迟子项接口时详情和需求主行可查看，子项失败后可单独重试。行内保存只产生一次写请求，当前输入禁用，全页无遮罩。
- 看板重新进入、页面刷新复用有效快照；主动刷新重新查询六列；会话结束清缓存并取消待持久化任务。
- 工作星图30次指针移动不重挂载场景；WebGL模式拖动仍使用同一Canvas，暂停后可手动旋转，减少动画设置生效。

## 压力场景对照

同一机器、8张相同条件的自动高度卡片、1000条模拟任务、每张预览5条：

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 首页实际任务行 | 8000 | 40 |
| DOM元素 | 80224 | 638 |
| 一次拖拽中的任务数组排序次数 | 82 | 8 |
| 拖拽P95帧间隔 | 167ms | 17ms |
| 拖拽最大帧间隔 | 400ms | 67ms |
| 主入口JS / gzip | 570.23 / 177.60KB | 403.90 / 127.11KB |

优化后的自动高度压力场景仍观察到一次81ms长任务，不能据此保证所有设备恒定60fps。Three.js独立块约920.70KB，继续仅在启用3D时加载；分包改善入口资源量，不代表真实Jira冷接口耗时变化。未覆盖Windows实机或原生WKWebView性能。
